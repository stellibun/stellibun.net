Abyssmal

Created: 03/08/2026

More Info Game Page

Abyssmal is a roguelite platformer inspired by Nullscape, Subnautica, and Parkour Reborn.

The game starts above the ocean, in an oil rig, and eventually will start going deeper and deeper into the ocean. You select an enemy, punishment, and objective every round, with enhancements (shops) sprinkled in.

The game is still in development, and may sometimes not be up for development purposes.
